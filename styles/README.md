# Styles

Each style is a directory with a mkgmap style (`lines`, `polygons`, `points`, `options`,
`info`, `version`) and a TYP source in `typ/` that mkgmap compiles. The default style
`topo50/` and the overlay style `skoter/` are added in milestones M1–M3.
Draft rules from the planning spikes are in `spikes/03-mkgmap/style/` (not production).
